# tradinjournal.com ("Tradinjournal 2.0") — demo frames

Reference screenshots pulled from the YouTube video **"Live Trading From Europe!"**
by *Traders Paradise Live* (https://youtu.be/N-pgPO3QFB8), product-demo segment
**02:35–03:50**. Filmed as a phone pointed at a laptop on a plane, so frames are
glare-y/reflective. 100 frames, ~0.75s apart (`frame_0001` ≈ 02:35 … `frame_0100` ≈ 03:49).

Kept as build reference for TRADElogs — competitor UI, do **not** ship any of it.

## Key idea to borrow
Hot Topics ranks news **by the user's traded symbols** — each card carries a `YOUR MARKET`
badge, a numeric relevance score, and a symbol-specific "what to watch" line, plus a
symbol tab row to pivot the feed. No economic calendar was shown in this segment.
